# Aula 13 - Desenvolvimento Backend com Node.js 

Este repositório contém a atividade prática desenvolvida durante a **Aula 13**, focada na criação e estruturação de uma API/servidor backend utilizando Node.js.

## Estrutura do Projeto

O projeto está organizado da seguinte forma:

*   **`src/`**: Contém o código-fonte principal da aplicação (rotas, controladores, serviços, etc.).
*   **`dados/`**: Pasta destinada ao armazenamento de arquivos de dados ou mocks utilizados pela aplicação.
*   **`prints/`**: Capturas de tela que comprovam o funcionamento e os testes realizados na aplicação (ex: rotas testadas no Insomnia/Postman).
*   **`server.js`**: Arquivo de entrada (entry point) responsável por inicializar o servidor.
*   **`package.json`**: Gerenciador de dependências e scripts do projeto.
*   **`.gitignore`**: Arquivo para ignorar pastas desnecessárias no versionamento (como a `node_modules`).

## Tecnologias Utilizadas

*   [Node.js](https://nodejs.org) - Ambiente de execução JavaScript Server-side.
*   [JavaScript](https://mozilla.org) - Linguagem utilizada no desenvolvimento do ecossistema.

##  Como Executar o Projeto 

### Pré-requisitos
Antes de começar, você vai precisar ter instalado em sua máquina o [Git](https://git-scm.com) e o [Node.js](https://nodejs.orgpt-br/).

### Paso a passo

1. **Clonar o repositório:**
   ```bash
   git clone https://github.com
   ```

2. **Acessar a pasta do projeto:**
   ```bash
   cd aula13
   ```

3. **Instalar as dependências:**
   ```bash
   npm install
   ```

4. **Iniciar o servidor:**
   ```bash
   npm start
   ```
